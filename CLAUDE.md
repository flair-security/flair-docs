## Build & test commands

```bash
# Install
npm ci

# Dev server
npm start

# Production build
npm run build

# Serve the production build locally
npm run serve

# Type check
npm run typecheck

# Lint markdown
npm run lint:md

# Cut a versioned snapshot of architecture/ or adr/ (only once a release warrants freezing them)
npm run docs:version:architecture -- <version>
npm run docs:version:adr -- <version>
```

## Repo structure

```text

  docusaurus.config.js  ← one plugin-content-docs instance per section below

  src/css/custom.css
  static/img/           ← logo.svg / favicon.svg still needed, see static/img/README.md

    setup/              ← dev environment setup (mostly TBD — most repos are pre-MVP)
    architecture/        ← system design (versioned)
    adr/                 ← architecture decision records (versioned)
    cicd/                ← per-repo CI/CD pipeline docs
    audits/              ← audit category index (real audits live in flair-security/.github/docs/audits/)
    backlog/              ← how FLAIR's GitHub Projects-based backlog works
    workflow/             ← the agentic dev workflow (PO/Architect/Security/QA/Dev/PR-Review agents)
    specs/                ← reserved for frozen per-User-Story specs, once/if FLAIR adopts that practice
```

Never delete a story file — they are the audit trail.
