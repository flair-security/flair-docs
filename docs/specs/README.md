# Specs

This section is reserved for frozen per-User-Story specs, should the org adopt that practice.

FLAIR does not currently have an equivalent process. Its agentic workflow (see `AGENT.md` in
`flair-security/.github`) is Acceptance Criteria Driven Development with continuous 0–100
confidence gates, not a spec-freeze step before merge — there is no "Doc Agent" or similar role
that freezes a functional/technical spec ahead of implementation the way some other
organizations do. If that changes, this page is where the resulting specs would live.
